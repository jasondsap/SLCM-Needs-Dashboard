🚀 QUICK START (3 STEPS):
═══════════════════════════════════════════════════════════════

1. DOWNLOAD
   Download the "slcm-dashboard" folder

2. OPEN & READ
   Open the folder and read: START_HERE.md

3. RUN
   Mac/Linux: Run ./quick-start.sh
   Windows:   Run quick-start.bat
   
   OR manually:
   $ cd slcm-dashboard
   $ npm install
   $ npm run dev
   
   Then visit: http://localhost:3000
